# 和語アトラス（wago-atlas）・M1 補助動詞

> **核心维度：大和言葉（和語）。核心目标：以和语维度全面覆盖 JLPT N5～N1 及以上所有考点。**
> M1 交付：補助動詞 20 型的单文件课件（和語エンジン解説＋JLPT 真题命中＋六层题库）。

- 成品：`index.html`（单文件、离线可用、内嵌 TTS）
- 数据：`data/hojodoushi.json`（20 型）＋ `data/exams/hojodoushi.json`（真题命中句，带出典）
- 数据源：本地真题库 `../jlpt-question-bank/`（N2-N5）＋ `../jlpt-n1-question-bank/`（N1）

## M1 内容

| 维度 | 20 型 |
|---|---|
| 試行・準備・完了 | 〜てみる／〜ておく／〜てしまう／〜ている／〜てある |
| 方向・授受 | 〜てくる／〜ていく／〜てくれる／〜てもらう／〜てあげる／〜てやる |
| 意志・開始・継続 | 〜てみせる／〜始める／〜続ける／〜終わる |
| 徹底・中途 | 〜切る／〜込む／〜抜く／〜かける／〜直す |

每型带：**Engine**（実語→機能語の文法化説明）・**Blueprint**（一句话机制）・
2 例句＋TTS・**JLPT 真题命中句**（N1-N5，出处注明）。

## 构建

```bash
python3 build/extract_exams.py   # 从本地 N1-N5 题库抽真题命中句 → data/exams/
python3 build/build.py           # TTS 合成 + 题库生成 + 单文件 index.html
```

## 题库（六层）

📝 真題（原句）・✍️ 穴埋め・📘 意味認識・🎧 聴解判別・🎧 意味理解・🎧 書き取り
（＋前端 🎲 混合交错、📕 错题本 `localStorage: wago-wrong`）。
