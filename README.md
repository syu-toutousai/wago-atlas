## 文法化度（補助動詞）

`grammaticalization` 字段把 20 个補助動詞按「実語との距離」分三帯（連続体，非二分）：

| 帯 | 数 | 条目 | 判据 |
|---|---|---|---|
| 実語寄り | 8 | てくれる・てもらう・てあげる・てやる・始める・続ける・終わる・直す | 語彙義がほぼそのまま（授受の方向／局面動詞） |
| 中間 | 8 | てみる・てくる・ていく・てみせる・切る・込む・抜く・かける | 方向・比喩的拡張の中間段階 |
| 文法化済み | 4 | ておく・てしまう・ている・てある | アスペクト・状態の純マーカー（存在・配置動詞の語彙義は脱落） |

详情卡与一覧卡显示徽标「実語寄り／中間／文法化済み」；📊 観測 Tab 有「補助動詞の文法化ラダー」三帯全览。

## 抽取品质（真題コーパス）

- 短い機能語（けど・でも・なお・さも…）は**境界付き STRICT 正規表現**で複合語・別語内部の誤命中を排除（例：けど←「どけどけ」、でも←「どなたでも」、なお←「小さなお」）。
- 「（注…」词典行・空欄断片・並べ替え ★・6 字未満の断片はコーパスから除外。
- 手動除外は `data/exam_blocklist.json`。
- 真題句クイズの干扰项は**同维度**（補助動詞/接続表現/副詞）から抽出。
- 再抽出手順: `python3 build/extract_exams.py && python3 build/build.py`。

## 构建

```bash
python3 build/extract_exams.py   # 本地 N1-N5 题库 → data/exams/*.json（按维度）
python3 build/build.py           # TTS 合成 + 题库生成 + 单文件 index.html
```
